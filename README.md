# 🐍 Python Learning Tracker

A beautiful, interactive web app to track your Python learning journey through 35 hands-on projects — from beginner to expert.

![Python](https://img.shields.io/badge/Learning-Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Projects](https://img.shields.io/badge/Projects-35-green?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-In%20Progress-yellow?style=for-the-badge)

## ✨ Features

- 📋 **35 Python Projects** organized by difficulty (Beginner → Expert)
- ⏱️ **Built-in Timer** — track time spent on each project
- 📅 **Activity Calendar** — GitHub-style heatmap of your study days
- 📊 **Progress Dashboard** — see your stats at a glance
- 📝 **Notes** — write notes for each project
- 🔥 **Streak Counter** — stay motivated with daily streaks
- 💾 **Auto-Save** — all progress saved in your browser
- 📱 **Fully Responsive** — works on desktop, tablet, and mobile

## 🚀 Getting Started

1. Clone this repo:
   ```bash
   git clone https://github.com/YOUR_USERNAME/python-learning-tracker.git
   ```
2. Open `index.html` in your browser — that's it!
3. Start with **Project #1 (Calculator)** and work your way through!
